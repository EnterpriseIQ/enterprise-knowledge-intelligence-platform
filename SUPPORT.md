# Support

## Getting Help

If you need help with EnterpriseIQ, there are several ways to get support:

1. **Read the Documentation:** Our [Documentation](docs/index.md) is the best place to start. It covers installation, configuration, and advanced usage.
2. **Review the FAQ:** Check the [FAQ](docs/FAQ.md) for commonly asked questions.
3. **GitHub Discussions:** Join our [GitHub Discussions](https://github.com/enterpriseiq/enterprise-knowledge-intelligence-platform/discussions) to ask questions, share ideas, and interact with the community.
4. **GitHub Issues:** If you've found a bug or want to request a feature, please open an [Issue](https://github.com/enterpriseiq/enterprise-knowledge-intelligence-platform/issues).

## Enterprise Support

For organizations requiring guaranteed SLAs, dedicated support channels, or custom deployments, we offer Enterprise Support plans. Please contact `sales@enterpriseiq.io` for more information.

## Security Issues

If you discover a security vulnerability, please refer to our [Security Policy](SECURITY.md) for reporting guidelines. **Do not report security vulnerabilities on the public issue tracker.**
